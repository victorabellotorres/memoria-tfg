LaTeX del TFG, local — no hay remoto de Overleaf (requiere cuenta premium que no tenemos). Se versiona como parte de este mismo repo.

Compilar con `latexmk` o `tectonic`. Si en algún momento se quiere usar el editor de Overleaf puntualmente, se sube un zip manualmente (New Project → Upload Project, gratis) y luego se vuelve a bajar el zip para reincorporar cambios — no hay sync automático.
