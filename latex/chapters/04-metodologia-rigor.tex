\chapter{Metodología y rigor}
\label{chap:metodologia}

\section{Metodología de trabajo}

El proyecto se dividirá en tareas pendientes, en curso y terminadas. Se
avanzará desde la preparación de datos y la línea base hasta el entrenamiento
y la comparación de modelos. Git permitirá registrar los cambios en el código
y la memoria. Antes de ampliar los experimentos se probará el proceso con un
subconjunto piloto.

\section{Método experimental}

Se usarán las imágenes RGB y las particiones oficiales de Nutrition5k
\citep{thamesNutrition5kAutomaticNutritional2021}. Tras la prueba piloto, la
línea base y los modelos visuales se evaluarán con la partición completa
disponible y un protocolo común.

Para cada modelo se informará por separado del error absoluto medio y del error
porcentual definido por Nutrition5k para masa, calorías, grasas,
carbohidratos y proteínas. También se medirán el tamaño y el tiempo de
inferencia. Al menos un modelo se ejecutará en el entorno de recursos limitados
que se defina. El dispositivo, las métricas adicionales y el número de
repeticiones siguen siendo \textbf{TBD}.

\section{Seguimiento y rigor}

Se probarán la preparación de datos y el cálculo de métricas, y se guardarán
las configuraciones, predicciones y resultados. Las decisiones sobre los
modelos se tomarán sin consultar el conjunto final de prueba. El avance se
revisará con la dirección del TFG según su disponibilidad. La comparación
explicará también los casos de fallo y las limitaciones de los datos.
